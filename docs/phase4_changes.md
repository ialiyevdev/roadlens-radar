# Phase 4 file map

Phase 4 extends the existing local FastAPI/React application to manage field observations, camera geometry, manual vehicle annotations and independent-reference evaluation. Project versions are 0.4.0. No new runtime package, external service or public hosting was introduced. Phase 1–3 workflows remain available.

Backend filenames below are relative to `backend/roadlens/`, backend tests to `backend/tests/`, frontend files to `frontend/src/`, scripts to `scripts/` and documentation to `docs/`.

The [architecture](architecture.md) describes lifecycle, coordinate and persistence boundaries. The [camera procedure](camera_intrinsics.md), [annotation workflow](annotations.md), [field collection guide](real_world_validation.md) and [field example schema](../examples/field/README.md) cover daily use. [Verification](testing.md) contains the actual full-suite/build/browser results; [performance](performance.md) identifies the measured workload and raw artifact behind each timing.

The new field fixture yields four eligible synthetic comparisons: MAE 2.0 km/h, RMSE 2.1213 km/h and bias +0.5 km/h. Its baseline/improved values and scripted annotation IDs demonstrate software arithmetic and retention. They are not detector accuracy, lens-improvement or real-world speed results. Camera fitting uses generated corners/images, and performance uses generated pixels/recordings. Actual physical-camera geometry, moving-roadway identities and independent reference-speed evidence remain to be collected.
