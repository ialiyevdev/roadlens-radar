# Phase 5 file map

Phase 5 adds Traffic Intelligence to the existing local RoadLens Radar application. It consumes the established YOLOX-S detector, temporary tracker, calibrated speed results, timestamp diagnostics and Phase 4 manual field labels. Versions are 0.5.0. No runtime dependency, database, paid API or cloud service was added.

Backend modules below are relative to `backend/roadlens/`, tests to `backend/tests/`, frontend files to `frontend/src/`, and scripts to `scripts/`.

The runtime engine is incremental. Per-frame rendering reads current overlay state; HTTP requests produce full snapshots, statistics and exports. Configuration edits receive new version IDs, segment coverage and keep previous events. A source-pixel geometry change clears current manual definitions rather than transforming them; previous configuration/event records remain archived.

Histories retain at most 10,000 crossing events, 10,000 zone events, 5,000 occupancy samples, 10,000 coverage segments, 128 configuration versions and bounded identity/region summaries. Omission diagnostics accompany retained-subset exports. Unfiltered lifetime counts remain separate from the event ring. Source timestamps determine crossing times, dwell and coverage; processing or browser polling clocks do not supply elapsed traffic time.

The [architecture](architecture.md) describes lifecycle, classification evidence, duplicate suppression, coordinate boundaries and storage limits. The [traffic guide](traffic_intelligence.md) covers drawing, interpreting and exporting results. [Testing](testing.md) records actual final suite/build/browser outcomes, while [performance](performance.md) identifies each measured workload and raw result.

Synthetic trajectories, scripted predictions/manual labels and rendered recordings establish deterministic software behavior. Running the real detector on a supplied still-image replay establishes a separate CPU/model execution result. Neither category establishes roadway counting/classification accuracy, camera completeness, congestion truth or independently validated metric speed. Held-out physical footage, reviewed crossing identities/classes and synchronized independent speed references remain to be collected.
